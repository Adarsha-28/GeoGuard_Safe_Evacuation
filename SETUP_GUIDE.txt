═══════════════════════════════════════════════════════════
  🛡️ GeoGuard V1 - Chennai Flood Risk & Evacuation System
  Quick Setup Guide
═══════════════════════════════════════════════════════════

📌 PREREQUISITES:
- Python 3.10+ installed
- Command prompt or PowerShell

═══════════════════════════════════════════════════════════
STEP 1: Navigate to GeoGuard Folder
═══════════════════════════════════════════════════════════

cd C:\Users\ADARSHA\Desktop\GeoGuard

═══════════════════════════════════════════════════════════
STEP 2: Install Dependencies
═══════════════════════════════════════════════════════════

pip install -r requirements.txt

═══════════════════════════════════════════════════════════
STEP 3: Run Automated Test Suite
═══════════════════════════════════════════════════════════

python -m pytest tests/ -v

═══════════════════════════════════════════════════════════
STEP 4: Start the Server
═══════════════════════════════════════════════════════════

python main.py

You should see:
[READY] Server operational at http://localhost:8000/
[READY] Press Ctrl+C to stop the server

═══════════════════════════════════════════════════════════
STEP 5: Open the Web Dashboard
═══════════════════════════════════════════════════════════

Open your browser and navigate to:
http://localhost:8000/frontend/index.html

═══════════════════════════════════════════════════════════
✅ FEATURES IN V1
═══════════════════════════════════════════════════════════
- Chennai flood risk grid map (Low, Moderate, High, Severe)
- 25 Relief shelters with live available capacity
- Nearest shelter discovery
- Safe evacuation routing with OSRM integration
