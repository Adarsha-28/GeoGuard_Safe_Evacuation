  🛡️ GeoGuard - Chennai Flood Risk Monitor
  Complete Setup Guide
═══════════════════════════════════════════════════════════

📌 IMPORTANT: Follow these steps EXACTLY

═══════════════════════════════════════════════════════════
STEP 1: Open Command Prompt
═══════════════════════════════════════════════════════════

Press: Windows Key + R
Type: cmd
Press: Enter

═══════════════════════════════════════════════════════════
STEP 2: Navigate to GeoGuard Folder
═══════════════════════════════════════════════════════════

Copy and paste this command:

cd C:\Users\ADARSHA\Desktop\GeoGuard

Press: Enter

You should see: C:\Users\ADARSHA\Desktop\GeoGuard>

═══════════════════════════════════════════════════════════
STEP 3: Start the Server
═══════════════════════════════════════════════════════════

Copy and paste this command:

python -m http.server 8000

Press: Enter

You should see:
Serving HTTP on :: port 8000 (http://[::]:8000/) ...

⚠️ KEEP THIS WINDOW OPEN! Don't close it!

═══════════════════════════════════════════════════════════
STEP 4: Open Your Browser
═══════════════════════════════════════════════════════════

Open Chrome, Firefox, or Edge

Copy and paste this URL:

http://localhost:8000/web/test.html

This will test if everything is working.

If the test passes, go to:

http://localhost:8000/web/index.html

═══════════════════════════════════════════════════════════
❌ IF SOMETHING GOES WRONG
═══════════════════════════════════════════════════════════

Problem: "Cannot load data" or blank map

Solution:
1. Press Ctrl+C in the command prompt
2. Make sure you're in the GeoGuard folder (not web folder)
3. Type: cd
4. If it shows "...GeoGuard\web", type: cd ..
5. Start server again: python -m http.server 8000
6. Refresh browser

═══════════════════════════════════════════════════════════

Problem: "Port 8000 already in use"

Solution:
Use a different port:
python -m http.server 8080

Then open: http://localhost:8080/web/index.html

═══════════════════════════════════════════════════════════

Problem: Python not found

Solution:
1. Check if Python is installed: python --version
2. If not installed, download from: https://www.python.org/
3. During installation, check "Add Python to PATH"
