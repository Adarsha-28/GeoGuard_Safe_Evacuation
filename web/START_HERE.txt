# 🛡️ GeoGuard - Chennai Flood Risk Monitor

## ✅ QUICK START (Follow These Steps)

### Step 1: Open Command Prompt
Press `Win + R`, type `cmd`, press Enter

### Step 2: Navigate to GeoGuard folder
```bash
cd C:\Users\ADARSHA\Desktop\GeoGuard
```

### Step 3: Start the server
```bash
python -m http.server 8000
```

You should see:
```
Serving HTTP on :: port 8000 (http://[::]:8000/) ...
```

### Step 4: Open your browser
Go to: **http://localhost:8000/web/index.html**

---

## 🎯 What You Should See

✅ A dark blue dashboard with:
- Header showing "🛡️ GeoGuard"
- Left panel with risk statistics
- Center map showing Chennai with colored zones
- Right panel with alerts and emergency contacts

## ❌ Troubleshooting

### Problem: "Cannot load data" error
**Solution:** Make sure you're running the server from the **GeoGuard** folder (not the web folder)

```bash
# Check current directory
cd

# If you're in the web folder, go up one level
cd ..

# Now start server
python -m http.server 8000
```

### Problem: Port 8000 already in use
**Solution:** Use a different port
```bash
python -m http.server 8080
```
Then open: http://localhost:8080/web/index.html

### Problem: Map not showing
**Solution:** 
1. Check browser console (F12)
2. Look for error messages
3. Make sure you have internet connection (for map tiles)
